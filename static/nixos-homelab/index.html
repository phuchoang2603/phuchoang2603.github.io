NixOS Homelab

One flake builds a desktop, a server and a MacBook from shared modules. Source on GitHub

Flake inputs

nixpkgs (unstable) home-manager nix-darwin agenix stylix vicinae extensions

Hosts

nixos-desktop

x86_64-linux, nixosConfigurations
modules/commonbase, nix settings, Cachix
modules/nixosaudio, desktop, hardware
hosts/nixos-desktopmachine settings and hardware
home/base + home/linuxCLI and GUI apps, Hyprland, Waybar, Hyprlock, Mako, fcitx5
Stylixsystem-wide theme

nixos-server

x86_64-linux, nixosConfigurations
modules/commonbase, nix settings, Cachix
modules/serverDocker, storage, SSH, NVIDIA, agenix secrets, deployment
hosts/nixos-servermachine settings and hardware
home/base + home/servershell and CLI tools

macbook

aarch64-darwin, darwinConfigurations
modules/commonbase, nix settings, Cachix
modules/darwinDock, Finder, trackpad, privacy, Homebrew
hosts/macbookmachine settings
home/base + home/darwinCLI and GUI apps, AeroSpace, Karabiner
Stylixsystem-wide theme

Server containers

Defined as NixOS modules under modules/server/containers, run by Docker, with Traefik in front and credentials encrypted by agenix.
